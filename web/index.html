02 / COLLECT

측정 기록

같은 조건에서 두 앱을 번갈아 실행하세요. run ID는 각 페어에 동일하게 입력합니다.

새 관찰값

필수 항목 *

고정 FPS는 두 프레임 번호와 FPS가 필수입니다. PTS 판독은 표시 시각이 필수이고, 원본 PNG의 1부터 시작하는 프레임 번호 두 개를 함께 저장할 수 있습니다. 시간은 PTS 차이로 계산합니다.

한 페어의 첫 시도에서만 반대 앱 준비를 누르세요. 두 번째는 기록 저장을 누릅니다. 민감정보는 입력하지 마세요.

영상 측정 도구

브라우저 안에서만 재생

외부 촬영이나 화면 녹화에서 탭과 실제 콘텐츠 표시 시점을 찾으세요. 화면 녹화의 터치 표시는 실제 접촉보다 늦을 수 있습니다. 선택한 영상은 서버에 전송되지 않습니다.

검증된 프레임 번호로 계산

프레임 기준

영상 편집기에서 읽은 시작·끝 프레임과 확인한 고정 FPS를 입력하세요. 계산식은 (끝 − 시작) ÷ FPS × 1000입니다. 가변 FPS 영상은 이 계산식이 맞지 않으므로 각 프레임의 타임스탬프를 읽어야 합니다. 이 도구는 고정 FPS 여부를 자동 확인하지 않습니다.

프레임 번호와 고정 FPS를 입력하면 시간이 계산됩니다.

프레임 표시 시각으로 계산

가변 FPS 가능

영상 편집기나 ffprobe에서 시작·끝 프레임의 PTS(초)를 확인하세요. 단순히 영상 전체 길이를 프레임 수로 나눈 FPS는 사용하지 않습니다.

두 프레임의 표시 시각을 입력하면 차이가 계산됩니다.

재생 위치로 빠르게 표시

근사치

브라우저 재생 위치는 프레임을 보장하지 않습니다. 정확한 수치가 필요하면 위의 검증된 프레임 번호를 사용하세요.

현재 0.000 s—
탭: —콘텐츠: —
두 시점을 표시하면 근사 시간 차이가 나옵니다.

01

조건 고정

같은 기기·통신망·종목·시장 상태·로그인 상태에서 앱 실행 순서를 교차합니다.

02

영상으로 체감 측정

탭·첫 반응·가격 표시를 각각 표시합니다. 외부 촬영을 우선하고, 화면 녹화만 가능하면 프레임 오차를 기록합니다.

03

원인 가설 점검

별도 Perfetto 추적으로 프레임 지연을 보고, 자체 모의 시세 서버에서 캐시·전송·페이로드를 하나씩 검증합니다.

해석의 경계

이 화면의 숫자로 “어느 회사 서버가 더 빠르다”거나 “특정 프로토콜 때문에 빠르다”는 결론을 낼 수 없습니다. 관측된 전송 방식은 사실로 기록하되, HTTP 버전과 내부 처리 시간은 추가 근거 없이는 미확인으로 둡니다.

공개 자료의 단서

토스증권의 2022년 발표 ↗는 시세 WebSocket/HTTP API 경로를 설명하고, 한국투자증권 개발자용 Open API ↗도 WebSocket을 제공합니다. 두 자료만으로 현재 고객용 모바일 앱의 속도 차이는 설명할 수 없습니다.
