# 2026-10-15 예비 측정: 종목 상세 화면 표시 시간

이 문서는 Galaxy S24+ 자체 화면 녹화 네 건을 프레임 PTS로 판독한 **예비 결과**다. 원본 영상과 프레임에는 제3자 콘텐츠가 나타날 수 있어 공개 자료에 포함하지 않는다. 본 실험의 60회 시도와 30페어에는 이 네 건을 합산하지 않는다.

## 측정 조건과 지표

- 기기: Galaxy S24+ (`SM-S926N`), Android 16. 촬영 후 확인한 앱 버전은 토스 5.280.0, 한국투자 2.28.01이다. One UI 표시 버전은 확인 전이다.
- 네 시도는 2026-10-15 16:19~16:20 KST에 촬영했다. [KRX 정규장 09:00~15:30](https://global.krx.co.kr/contents/GLB/06/0602/0602020204/GLB0602020204T1.jsp) 이후다. 사용자는 같은 Wi-Fi를 사용하고, 셀룰러 전환·VPN 없이 각 앱에서 해당 종목을 한 번 열었다가 검색 결과로 돌아오는 준비 동작을 동일하게 수행했다고 확인했다.
- 시작: 녹화 영상에 탭 표시가 처음 나타난 프레임. 완료: 선택 종목명과 **그 종목의** 0·빈칸·이전 종목 잔상이 아닌 가격 숫자가 함께 읽히는 최초 프레임. 시간은 `완료 프레임 PTS − 시작 프레임 PTS`다. 실제 손가락 접촉부터의 시간이나 서버 응답시간은 아니다.

| 종목·시작 화면 | 앱 | 시작→완료 프레임 | 측정 시간 |
|---|---|---:|---:|
| 삼성전자 005930 · 키보드 닫힘 | 한국투자 | 27→53 | 747.944 ms |
| 삼성전자 005930 · 키보드 닫힘 | 토스 | 59→143 | 1400.733 ms |
| SK하이닉스 000660 · 키보드 열림 | 한국투자 | 25→49 | 631.178 ms |
| SK하이닉스 000660 · 키보드 열림 | 토스 | 25→65 | 667.755 ms |

한 쌍씩 계산한 `토스 − 한국투자`는 삼성전자 **+652.789 ms**, SK하이닉스 **+36.577 ms**다. 각 조건의 표본은 **1쌍**이며, 두 조건 모두 한국투자를 먼저 실행했다. 종목과 키보드 상태가 달라 두 쌍을 한 조건의 반복 측정으로 합치지 않는다. 이 결과로 일반적인 앱 속도 순위나 차이의 원인을 말할 수 없다.

한국투자의 SK하이닉스 화면에서는 종목명이 바뀐 뒤 이전 종목 가격이 잠시 남았다. 그 값을 완료로 세지 않도록 완료 기준을 예비 판독 중 구체화했다. 토스 화면은 가격이 읽히기 시작한 뒤 밝기가 더 올라가는 구간이 있어, '최초 판독 가능'을 주 지표로 고정했다. 이 판독 기준을 [본 실험 계획](EXPERIMENT_PLAN.md)에 기록하고 본 실험 시작 전에 고정한다.

## 다음 실험

한 종목, 한 검색어, 같은 결과 행과 키보드 상태를 선택해 장중 세션에서 15블록 × 4회, 총 60회 촬영한다. 블록은 `토스-한국투자-한국투자-토스`와 그 역순을 번갈아 사용한다. 모든 시도와 실패를 사전에 생성한 대장에 남기고, 예비 기록과 별도 DB에서 분석한다. 화면 영상만으로 두 앱의 내부 프로토콜, 캐시 적중, 서버 처리 시간, 시세 최신성을 판정하지 않는다.
